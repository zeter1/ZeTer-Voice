# Архитектура ZeTer Voice

## Слои

`ZeTer Voice.py` — стабильная точка запуска и legacy facade.

`runtime.py`, `sapi.py`, `windows_tools.py`, `problem_logger.py` — компактные compatibility facades. Реальная логика вынесена в owner-модули (`runtime_*`, `sapi_*`, `windows_*`, `problem_logger_*`). Старые импорты сохранены.

`task_*.py` — функциональность одной пользовательской вкладки. Крупные mixin’ы дополнительно собраны из узких частей: UI build/status/state, source tracking/capture/file I/O, preview player/delete/controls.

`app_*.py` — главное окно. Workspace, tabs, persistence, recovery, hotkeys, event dispatch и shutdown имеют отдельных владельцев.

`task_conversion_worker.py` использует общее состояние задания от синтеза до очистки. Для точечной правки выбери этап по метке в [карте MP3](WORKER_MAP.md).

## Совместимость

Public composition names (`ProblemLogger`, `GlobalCopyHotkeyMonitor`, `TaskUiMixin`, `TaskSourcesMixin`, `TaskPreviewRuntimeMixin`, `AppEventsMixin`, `AppWorkspaceMixin`, `AppRecoveryHotkeysMixin`) сохранены. Cross-mixin вызовы через `self` продолжают работать через MRO.

Пути пользовательских данных по-прежнему находятся рядом с корнем программы (либо fallback storage), а не внутри `tts_app/`. Автозапуск Windows использует `ZeTer Voice.py` для исходного кода и путь к EXE для сборки.

## Потоки и доставка результатов

- Tk владеет окнами, вкладками, переменными и обработкой очереди в `app_event_dispatch.py`. Фоновый результат применяется к соответствующему запуску чтения или MP3. При закрытии учитываются фоновые операции и незаписанное состояние. Владельцы — `app_shutdown.py` и `app_workspace_save.py`.
- `WindowsCopyCapture` разделяет перехват клавиш, чтение буфера и доставку в Tk. Поток буфера готовит снимок Unicode целиком. Tk проверяет актуальность назначения и добавляет снимок в закреплённую вкладку. [Контракт захвата](PROJECT.md#захват-текста)
- При автосохранении Tk подготавливает снимок, а запись файлов может идти в фоне. При явном закрытии программа проверяет сохранение актуального текста и списка вкладок. [Сохранение и восстановление](PROJECT.md#сохранение-и-восстановление-вкладок)
- Чтение и конвертация работают на фоне. Пользовательский результат появляется после проверок соответствующего этапа. При завершении MP3 звуковой файл сначала проверяется, затем публикуется. [Карта работника MP3](WORKER_MAP.md)

## Отзывчивость окна

Редактор отключает автоматический перенос очень длинной логической строки и сохраняет текст и закладки. Повторный подсчёт использует кеш до изменения содержимого. Блокировка одного экземпляра защищает работу с данными и горячими клавишами в пользовательской сессии Windows. Независимый поток может сохранить снимок стека при задержке Tk. [Как найти снимок зависания](LOGGING_FOR_AI.md#диагностика-зависания-окна)
